# Fictional example: Paper Kite weekly workshop email
All organizations, facts and content below are invented for demonstration. Design only; no model or user testing has been run.

## Brief
Create a repeatable draft workflow for a beginner sketching workshop email. Audience: adult beginners. Deliverable: one email draft, fewer than 120 words. Owner/reviewer: workshop coordinator.

## Context ledger
- F1: Workshop takes place on 6 November 2026 at 18:00 UTC; source: fictional brief, 2026-10-16; permitted use: this example only; not a real event.
- F2: Price is £12 and materials are included; same source and permission.
- S1: Friendly, calm voice; same brief, stylistic preference.
- U1: Registration URL absent. Do not invent one.

## Workflow
| Step / owner | Inputs | Action and short prompt | Output | Check | Failure route |
|---|---|---|---|---|---|
| Intake / coordinator | F1,F2,S1,U1 | Collect only missing registration destination. | Brief and ledger | Separate facts/style | Mark URL unresolved |
| Outline / AI | F1,F2 | Plan invitation, details, CTA using only supplied facts. | Outline | All necessary details | Return missing details |
| Draft / AI | Outline,S1 | Write under 120 words; preserve date, time, price; use a labeled URL placeholder. | Draft v1 | No invented claims | Remove unsupported copy |
| Fact check / reviewer | F1,F2,draft | Compare every claim against ledger. | Claim review | Exact offer/date/time | Return to draft |
| Style check / AI | S1,draft | Improve clarity without changing facts. | Draft v2 | Friendly and concise | Retain factual wording |
| Handoff / coordinator | v2,review | Review final copy and supply URL before any send. | Approval packet | All blockers resolved | Hold sending |
